# Архив исходников в образе

`scripts/package-release.sh` кладёт сюда `officier-source.tar.gz` — исходники именно той версии,
из которой собирается образ. Образ раздаёт архив по адресу `/welcome/officier-source.tar.gz`,
на него ведут «Файл → О программе» и `/welcome/officier.html` (AGPLv3, раздел 13).

Если архива нет (сборка из git в CI), ссылка ведёт на репозиторий с ревизией сборки.
